About me

I’m a fullstack developer who likes owning a feature from the database table to the button someone taps. Most of my projects start with a question I want to answer, like how to keep a real-time game fair, or how to make economic news easier to read.

I care about clean APIs, fast interfaces and code the next person can follow. Outside of class I build side projects, read other people’s source code and write tests for things that break.
